## About the Project

I designed and built this site to show off a small business the way a real customer would want to see it: who the shop is, what it feels like inside, and why people keep coming back. Every layout is hand-written. No frameworks or templates.

## Built With

- **HTML5** with semantic elements (`section`, `figure`, `figcaption`)
- **CSS3** for styling, spacing, and typography
- **Flexbox** for page layout
- **Floats** to wrap text around images, like in the About section

## Features

- "About the Shop" section with a captioned photo and text wrapped beside it
- Custom layouts built with Flexbox and floats
- Clean, readable typography and spacing
- Semantic HTML structure

## What I Learned

- How floats work and why spacing a floated image needs `margin` on the float itself, not `padding` on the text next to it
- When to reach for Flexbox and when a float is the better tool
- Structuring a page with semantic HTML so it's easy to read and maintain
